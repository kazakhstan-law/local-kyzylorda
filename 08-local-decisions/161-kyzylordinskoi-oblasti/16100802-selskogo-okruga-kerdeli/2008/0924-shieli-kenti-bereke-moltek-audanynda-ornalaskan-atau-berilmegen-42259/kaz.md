# Шиелі кенті "Береке" мөлтек ауданында орналасқан атау берілмеген көшеге Өмірхан Жәрімбетовтің есімін беру туралы

Қазақстан Республикасының "Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы" Заңының 37-бабының 3-тармағын басшылыққа ала отырып және аудандық ономастикалық комиссия мәжілісінің 2007 жылғы 17 қыркүйектегі N 3 хаттамасына сәйкес ШЕШЕМІН:

1. Шиелі кентінде орналасқан аты жоқ көшеге ауданның ауылшаруашылығы саласында көп жылдар бойы абыройлы еңбек атқарған Өмірхан Жәрімбетовтің есімі берілсін.

   > *Ескерту. 1-тармаққа өзгерту енгізілді - Қызылорда облысы Шиелі ауданы әкімдігі Шиелі кенті әкімінің 2010.12.28 N 1103 Шешімімен.*

2. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік 10 күн өткен соң қолданысқа енгізіледі.

   > *Ескерту. 2-тармаққа өзгерту енгізілді - Қызылорда облысы Шиелі ауданы әкімдігі Шиелі кенті әкімінің 2010.12.28 N 1103 Шешімімен.*

3. Осы шешімнің орындалуына бақылау жасауды кент әкімінің

   орынбасары Ермахан Түменовке жүктелсін.

   *Кент әкімі М.Молдабаев*
