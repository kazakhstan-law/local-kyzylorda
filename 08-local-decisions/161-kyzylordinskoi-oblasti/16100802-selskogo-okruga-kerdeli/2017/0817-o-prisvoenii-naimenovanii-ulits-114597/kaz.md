# Көшелерге атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңына және Облыстық ономастика комиссиясының 2017 жылғы 26 сәуірдегі №1 қорытындысына сәйкес Керделі ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Шиелі ауданы Керделі ауылдық округінің Нартай Бекежанов ауылының оңтүстік бетіндегі атауы жоқ көшеге «Бибіхатша Смайлова» есімі берілсін.

<a id="p2"></a>

2. Шиелі ауданы Керделі ауылдық округінің Нартай Бекежанов ауылындағы атауы жоқ көшеге «Оразмахан Ақпанбетов» есімі берілсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау «Керделі ауылдық округі әкімінің аппараты» коммуналдық мемлекеттік мекемесінің жетекші маманы М. Әбжапбарға жүктелсін.

<a id="p4"></a>

4. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

   **Керделі ауылдық округінің әкімі**

   **Ф. Ержан**
