# Көшелерді қайта атау және атаулар беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасы Заңының 14-бабының 4) тармақшасына сәйкес, Ақжарма ауылдық округі тұрғындарының пікірін ескере отырып және облыстық ономастика комиссиясының 2023 жылғы 21 желтоқсандағы қорытындысы негізінде, Ақжарма ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Ақжарма ауылдық округі Баймұрат батыр ауылының атауы жоқ көшесіне Қымбат Тоқболатова атауы берілсін.

<a id="p2"></a>

2. Ақжарма ауылдық округі Баймұрат батыр ауылының келесі көшелері қайта аталсын:

   Тоғай көшесін Жақсылық Нұрашев көшесіне;

   Тоғай-1 көшесін Ибрахим Исмайлов көшесіне;

   Тоғай-2 көшесін Садықбек Досмағамбет көшесіне;

   Қырман көшесін Мұқашбек Айходжаев көшесіне;

   Қырман-1 көшесін Марат Қалиев көшесіне;

   Скважина көшесін Рахматулла Бақбергенов көшесіне.

<a id="p3"></a>

3. Ақжарма ауылдық округінің Талдыарал ауылындағы лепрозорий көшесінің атауы Владимир Сим болып өзгертілсін.

<a id="p4"></a>

4. Ақжарма ауылдық округі Талдыарал ауылындағы атауы жоқ көшелерге келесі атаулар берілсін:

   Темірхан Қоңырбаев көшесі;

   Мұсылманбек Мәжитов көшесі.

<a id="p5"></a>

5. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p6"></a>

6. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Ауылдық округ әкімі**

**С. Әбдіреев**
