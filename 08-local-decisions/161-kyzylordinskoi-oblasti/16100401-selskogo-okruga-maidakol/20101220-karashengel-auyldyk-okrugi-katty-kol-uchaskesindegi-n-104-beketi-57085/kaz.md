# Қарашеңгел ауылдық округі, "Қатты көл" учаскесіндегі N 104 бекетінің атауын өзгерту туралы

"Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы және "Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңдарын басшылыққа алып, Қарашеңгел ауылдық округіне қарасты Водокачка елді мекені тұрғындарының пікірін ескере отырып және аудандық ономастика комиссиясының 2010 жылғы 3 қыркүйектегі N 21 ұйғарымына сәйкес ШЕШЕМІН:

1. Қарашеңгел ауылдық округі, "Қатты көл" учаскесіндегі N 104 бекеті атауы Өтегенов Молдахмет атындағы N 104 бекеті атауына өзгертілсін.

2. Осы шешімнің орындалуын бақылауға алуды өз міндетіме қалдырамын.

3. Осы шешім алғаш ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
